# PROJECT PASSPORT — GENERALS: MOBILE COMMAND 🎖️

## 1. Технический статус
Проект реализован как **полнофункциональный технический фреймворк** для мобильной RTS уровня AAA.

## 2. Реализованные системы
### 🎮 Геймплей (Unity)
- **Юниты:** Три фракции (США, Китай, ГЛА) с легендарными юнитами и современными технологиями (БПЛА, РЭБ, Гиперзвук).
- **Механики:** Туман войны, ветеранство, построения, сбор ресурсов, дипломатия.
- **Обучение:** Интерактивная система туториала.

### 🌐 Сетевой режим (Backend)
- **Движок:** Node.js + Colyseus.
- **Фичи:** Матчмейкинг (ELO), Чат, Кланы, Турниры, Клановые войны.
- **Безопасность:** Authoritative Server валидация, анти-чит защита памяти.

### 🤖 Искусственный интеллект
- **Архитектура:** Адаптивный ИИ с профилями личностей генералов.
- **Gemini:** Динамические брифинги, генерация миссий и анализ матчей.

### 🛡️ Управление (Superadmin Control)
- **Dashboard:** Полный веб-интерфейс для мониторинга и управления.
- **Superadmin (ttajhacker@gmail.com):** Привилегированный доступ ко всем системам.
- **Live-Ops:** Рассылка уведомлений (Broadcast) и запуск глобальных ивентов в один клик.
- **Управление игроками:** Бан, изменение ELO, начисление валюты и подарков.

## 3. Инструкции по развитию
1. **Контент:** Настройка визуальной части в Unity Editor.
2. **Аналитика:** Мониторинг логов и статистики через админ-панель.
3. **Оперирование:** Проведение ежедневных турниров и Live-ивентов.
