# PROJECT PASSPORT — GENERALS: MOBILE COMMAND 🎖️

## 1. Технический статус
Проект реализован как **полнофункциональный технический фреймворк** для мобильной RTS уровня AAA.

## 2. Реализованные системы
### 🎮 Геймплей (Unity)
- **Юниты:** Три фракции (США, Китай, ГЛА) с легендарными юнитами (Paladin, Overlord, SCUD, MiG, Chinook).
- **Современные технологии:** Система БПЛА (FPV-дроны, Рой дронов) и РЭБ (Глушение радаров, Ложные цели).
- **Механики:** Туман войны, ветеранство, построения, сбор ресурсов, строительство зданий.
- **Герои:** Система прокачки героев и дерево талантов.

### 🌐 Сетевой режим (Backend)
- **Движок:** Node.js + Colyseus.
- **Фичи:** Матчмейкинг (ELO), Чат, Кланы, Турниры, Валидация действий (Анти-чит).
- **Администрирование:** Веб-дашборд для мониторинга сервера.

### 🤖 Искусственный интеллект
- **Архитектура:** Многоуровневый ИИ с аналитикой стиля игрока и тактическими паттернами.
- **Интеграция Gemini:** Динамические брифинги и послематчевый анализ тактики.

### 💰 Монетизация и Live-Ops
- **Battle Pass:** Система прогрессии и наград.
- **Events:** Динамические серверные события.
- **UI:** Умная система уведомлений и полноценное главное меню.

## 3. Инструкции по развитию
1. **Контент:** Настройка 3D-моделей и анимаций в соответствии с созданными скриптами.
2. **Баланс:** Использование `BalanceExporter` для калибровки характеристик.
3. **Карты:** Создание NavMesh-карт с учетом водных и сухопутных зон.
