# GRAPHICS & VISUAL STATUS REPORT — GENERALS: MOBILE COMMAND 🎨

## 1. Текущий статус программной части
Все графические системы подготовлены к приему ассетов:
- **VFX System:** Реализован `ParticlePool.cs`, поддерживающий мгновенный спавн взрывов, выстрелов и следов ракет.
- **Lighting:** `EnvironmentManager.cs` управляет динамическим циклом дня/ночи и погодными эффектами (песчаная буря).
- **Fog of War:** Система на базе текстур готова, юниты имеют компонент `VisionSource.cs`.
- **UI:** HUD и меню полностью сверстаны программно, ожидают финальных спрайтов и иконок.

## 2. Подготовка 3D-моделей
Для интеграции моделей в проект необходимо:
1. Импортировать FBX файлы в `Assets/Art/Models/`.
2. Настроить аниматоры (Idle, Move, Attack, Die).
3. Привязать префабы к соответствующим `UnitData` ScriptableObjects.
4. Настроить точки выстрела (FirePoint) для работы `AttackSystem.cs`.

## 3. Требования к качеству (Mobile AAA)
- **Polycount:** Юниты до 3000 полигонов, здания до 7000.
- **Textures:** Атласы 2048x2048 (PBR: Albedo, Normal, Metallic/Smoothness).
- **LOD:** Минимум 2 уровня детализации для каждого объекта.
