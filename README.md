# GENERALS: MOBILE COMMAND 🎖️

Современная мобильная RTS на Unity, вдохновленная классикой Command & Conquer: Generals.

## Актуальный статус (Технический фундамент)
Проект представляет собой полнофункциональный программный каркас (Framework), готовый к наполнению контентом.

### Реализовано и проверено:
*   **Ядро игры:** Управление состояниями, ресурсами и камерой.
*   **Боевая система:** Снаряды, типы урона, ПВО и спецспособности.
*   **Юниты всех фракций:** Техническая логика для США, Китая и ГЛА.
*   **Бэкенд:** Real-time сервер (Colyseus), авторизация, матчмейкинг.
*   **ИИ:** Адаптивное поведение и тактический анализатор.
*   **Администрирование:** Веб-панель Superadmin для мониторинга и управления.

## Технологии
*   **Unity 6.4+ (C#)**
*   **Node.js / Express / Colyseus**
*   **Google Gemini AI Integration**
*   **PlayFab / Firebase (Skeletons)**

Подробности реализации в `PROJECT_PASSPORT.md` и `REALITY_CHECK.md`.
