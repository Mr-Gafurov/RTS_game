# GENERALS: MOBILE COMMAND 🎖️

Современная мобильная RTS, вдохновленная классикой Command & Conquer: Generals.

## Особенности
*   Три уникальные фракции: США, Китай, ГЛА.
*   Система Героев-Генералов с уникальными способностями.
*   Морские сражения и авианосцы.
*   Продвинутый адаптивный ИИ.
*   Мультиплеер в реальном времени с защитой от читов.
*   Киберспортивные инструменты (Spectator Mode).

## Технологии
*   **Engine:** Unity 6.4+
*   **Backend:** Node.js, Colyseus
*   **AI:** Google Gemini Flash integration
